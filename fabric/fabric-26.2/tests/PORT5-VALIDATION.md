# port.5 验证

2026-09-08，Java 25、Fabric 26.2，保留 HMCL 原 33 个模组的隔离客户端，经 MCPFabric 驱动。

- build 通过 54 项回归，新增磁盘缓存重启、跨服隔离、大小预算、损坏、哈希拒绝、配额淘汰、关闭缓存及单位格式测试。
- 同一 788100 字节 PNG，不限速时单块传输 3251 ms，8 块传输 451 ms；总完成 3796 / 593 ms。是本机回环实测，公网速度受网络影响。
- 每玩家上传 102400 B/s 时，单块与 8 块分别传输 7701 / 7750 ms，总完成均 7934 ms；批量不绕过限速。
- 实际网络下载成功并加载纹理；客户端下载关闭磁盘缓存后测试限速下载。
- 重启客户端，原内存图片不存在；临时禁用该测试客户端的网络下载后，同一引用仍由磁盘缓存加载成功。
- 10 项真实协议断言通过；不传 window 字段仍支持旧版单块请求。
- 游戏聊天显示 Server stored image: 769.63 KiB → 167.46 KiB。
